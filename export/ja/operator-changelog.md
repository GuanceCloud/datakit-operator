# Operator 更新履歴

## 1.8.9(2026-06-23) {#cl-1.8.9}

- Cluster API の Pod クエリ性能を最適化し、eBPF 向けの簡易ビューに対応することで、大規模クラスターにおけるレスポンスボディのサイズと解析オーバーヘッドを削減しました（#94）

## 1.8.8(2026-05-28) {#cl-1.8.8}

- ddtrace のインジェクト時に、`check_annotation` 設定項目が想定どおりに反映されない場合がある問題を修正しました（#91）

## 1.8.7(2026-05-14) {#cl-1.8.7}

- Helm Chart と YAML のイメージタグを更新しました

## 1.8.6(2026-05-12) {#cl-1.8.6}

- Node.js ddtrace agent のインジェクトに対応しました（#89）

## 1.8.5(2026-05-09) {#cl-1.8.5}

- 一部のリソースインジェクト時に元の Pod フィールドが上書きまたは失われ、Pod が正常に動作しなくなる問題を修正しました（#88）

## 1.8.4(2026-04-03) {#cl-1.8.4}

- リソースのインジェクト時に initContainer の RestartPolicy 設定が破棄される場合がある問題を修正しました（#86）

## 1.8.3(2026-03-20) {#cl-1.8.3}

- PHP ddtrace agent のインジェクトに対応しました（#82）

## 1.8.2(2026-03-10) {#cl-1.8.2}

- 一部のケースで `/logging/configs` API が異常なレスポンスを返す問題を修正しました（#85）
- 一部のログ出力を最適化し、Operator の稼働状態を調査しやすくしました

## 1.8.1(2026-02-11) {#cl-1.8.1}

- `resourceFieldRef` 形式での環境変数のインジェクトに対応しました。コンテナのリソース制限値とリクエスト値（limits.cpu、limits.memory、requests.cpu、requests.memory）を参照できます（#84）
- Python ddtrace agent のインジェクトに対応しました（#81）
- クラスター内の Pod 関連データを取得するためのプロキシ API を提供しました（#79）

## 1.8.0(2026-01-29) {#cl-1.8.0}

- `admission_inject_v2` 設定項目に `check_annotation` フィールドを追加し、`admission.datakit/java-lib.version` の使用方法との互換性を確保しました（#81）
- 旧設定 `admission_inject.profiler` による Profiler のインジェクトとの互換性を確保しました（#81）

## 1.7.3(2026-01-08) {#cl-1.7.3}

- ClusterLoggingConfig CRD に対応する `from_beginning_threshold_size` 設定項目を追加しました（#80）

## 1.7.2(2025-12-18) {#cl-1.7.2}

- logfwd のインジェクト時にマウントエラーが発生する場合がある問題を修正しました（#78）

## 1.7.1(2025-12-17) {#cl-1.7.1}

- 旧設定との互換性に関する問題を修正しました（#77）
- `admission_inject_v2` 設定項目の `namespace_selectors` と `label_selectors` がいずれも空の場合、インジェクトを実行しないようにしました（#77）
- flameshot のインジェクトに設定項目 `enable_prometheus_annotations` を追加し、Prometheus.io Annotations を追加できるようにしました（#74）
- flameshot のポート設定方法を、環境変数 `FLAMESHOT_HTTP_LOCAL_ADDR` から `FLAMESHOT_HTTP_LOCAL_PORT` に変更しました（#75）
- logfwd は CRD 設定ソースを使用できるため、logfwd のインジェクト時に `log_configs` の設定が必須となっていた問題を修正しました（#76）

## 1.7.0(2025-12-12) {#cl-1.7.0}

- `admission_inject_v2` 設定項目を追加し、従来の `admission_inject` を置き換えるとともに、後方互換性を維持しました（#73）
- flameshot のインジェクトを追加し、従来の Profiler インジェクトを置き換えました（#72）
- セレクター `namespace_selectors` と `label_selectors` を同時に設定した場合の関係を、「または」から「かつ」に変更しました
- Annotation `admission.datakit/logfwd.log_configs` と `admission.datakit/logfwd.volume_paths` のサポートを削除しました（v1.6.X のみでサポート）
- Annotation `admission.datakit/java-lib.version` のサポートを削除しました（引き続き `admission.datakit/ddtrace.enabled:"false"` でインジェクトを無効化できます）

## 1.6.1(2025-12-02) {#cl-1.6.1}
